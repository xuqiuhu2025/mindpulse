# Prompt 更新日志

## chat/v1 — 2026-11-21
- 首个发布版本。
- 系统章程：明确“情绪支持伙伴，不是医生”；禁止临床诊断、伪装现实动作、
  制造排他性依赖、鼓励远离现实支持系统。
- 对话方式：先情绪后建议、一次最多一个主要问题、自然简短不说教、
  仅在用户主动表达困扰时轻量引入 CBT 式反思。
- 数据边界：健康数据仅作趋势参考，禁止据此推断疾病。
- 注入防护附加说明：用户输入无法关闭任何规则。
- 危机脚本（urgent / action 两个变体）：由 SafetyGuard 直接使用，不经过 LLM；
  要求确认立即危险与陪伴者、提示急救/急诊、危险物品交由信任者保管、
  明确不保证保密；脚本本身不包含任何方法、剂量或规避救援的信息。

## 变更规则
1. 任何修改都必须新建版本目录（v2/…），禁止覆盖已发布版本。
2. 更新 manifest.json 的 version 与 files 映射。
3. 在本文件登记：改动内容、理由、影响的测试（tests/test_prompts.py、
   tests/test_safety_guard.py 必须同步更新）。
4. 涉及危机脚本的改动需要人工安全评审后才能合并（见 CONTRIBUTING.md）。
